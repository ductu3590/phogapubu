# ADR-0001: Stack

- Ngày: 2026-11-13
- Trạng thái: đã duyệt (mặc định — ghi đè bởi spec bundle)

## Quyết định
Theo `~/.harness-kit/defaults.md` cho loại dự án tương ứng. Nếu file này chưa bị bundle ghi đè, orchestrator ghi lại stack thực tế ở đây khi làm T-000.

## Lý do
Đồng nhất với các dự án khác của anh Tú → agent và người đều quen, ít câu hỏi.
